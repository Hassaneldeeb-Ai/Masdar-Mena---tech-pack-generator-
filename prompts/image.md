# 02 — CONFLICT RESOLUTION

When SOURCE A and SOURCE B describe the same attribute:

### VISUAL ATTRIBUTE

Reference image has priority.

Example:

If the data describes a blue surface but the approved reference clearly
shows the product as black, do NOT recolour the product blue.

Preserve the approved visual appearance.

### TECHNICAL / NUMERICAL ATTRIBUTE

Structured data has priority.

Example:

If a measurement is specified as:

POM A = 72.5 cm ± 0.5 cm

do not visually estimate the dimension from the reference image.

Use the supplied technical value.

### UNCERTAIN ATTRIBUTE

If neither source provides sufficient evidence:

DO NOT INVENT IT.

Omit the detail.

Neutral omission is always safer than fabricated information.
